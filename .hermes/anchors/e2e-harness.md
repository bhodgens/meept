## Import path (the wave-1 leaves got this wrong)

    import "github.com/caimlas/meept/e2e/harness"

NOT "meept/e2e/harness". The module path is `github.com/caimlas/meept`
(`go.mod:1`).

## Build tag

Every file under `e2e/suites/<name>/` starts with:

    //go:build e2e

Then a package comment, then `package <name_snake_or_camel>`. Existing suites:
`package asyncturn`, `package goalloop`, `package delegate_seam` style is fine
as long as it is a valid Go identifier and matches sibling files in the suite.

Bus/RPC observation pattern (from `e2e/suites/async-turn/async_turn_test.go`):
suites open a persistent RPC session, call `bus.subscribe` with `{"topics":
[...]}`, then `bus.poll`. Subscriptions die with their connection, so subscribe
BEFORE the action under test.

## Manifest entry shape (`e2e/manifest.json`)

    "path_map": { "internal/agent/": ["dispatcher", "planner", ...] }
    "suites": [ { "name": "...", "dir": "e2e/suites/<name>", "status": "todo" } ]

`status:` is one of `todo|implemented|deferred`. Do NOT edit this file - the
orchestrator owns it.

## Test quality bar (wave 1 was rejected for violating all of these)

1. A test that only calls `t.Log(...)` is WORTHLESS and will be deleted. Every
   test must assert something with `if ... { t.Fatalf/t.Errorf(...) }` or
   testify (`github.com/stretchr/testify/assert`, `require` - already used in
   `internal/tools/builtin` tests).
2. RED must come from a COMPILE failure against the frozen contract (calling a
   not-yet-existing exported symbol) or a real assertion failure. A commented-out
   body is not RED.
3. Never write Go code inside a Python string. Use the write_file tool with the
   Go source directly.
4. Do not use `read_file` on large existing source; use `search_files` or
   `grep -n` in the terminal, then read the line range you need.
5. Package-level unit tests go in the package under test with `_test.go` and NO
   build tag. e2e suite tests go in `e2e/suites/<name>/` with the `e2e` tag.
