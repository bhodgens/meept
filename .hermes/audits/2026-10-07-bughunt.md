## Findings

### L1 (low, comment-vs-code): the "omitted when empty" wire claim is false

**Location:** `internal/queue/queue.go:453-459` (comment inside
`CompleteAttempt`'s publish block).

**What:** the comment says the token is *"Omitted when empty so the token-less
legacy shape is byte-identical on the wire."* The event is a
`map[string]any` passed to `models.NewBusMessage`, which does a plain
`json.Marshal` (pkg/models/types.go:35-37). An empty string in a
`map[string]any` marshals as `"claim_token":""` — the key is ALWAYS present.
The token-less legacy shape is NOT byte-identical on the wire.

**Why it is only low:** the sole consumer (the tactical guard) treats `""`
exactly as "no token presented" and degrades to the state-only predicate by
design, so behavior is correct. But the documented invariant is false, and the
empty-token wire shape has no pin —
`TestPersistentQueue_CompletionEventCarriesClaimToken`
(internal/queue/store_fail_attempt_test.go:274) covers only the non-empty
token.

**Fix shape (comment class, matches last wave's L2 disposition):** correct the
comment to state the key is always present with `""` on the legacy shape, or
conditionally build the map if byte-identity is actually wanted. No behavior
change required.

**Not fixed:** this session ran report-only per the bughunt contract — no
fix authorization in the request.
