# meept cluster subsystem audit (b4, 2026-10-31) — internal/cluster/

Never-audited scope: gossip transport, executor bridge, event store.
Cluster is OFF by default (components.go:2424 gates on
cfg.Cluster.Enabled) — the trust model when enabled is "the gossip
network is a trusted mesh".

## Parent-verified findings

1. [HIGH when enabled] gossip_transport.go:97 net.Listen("tcp") —
   plaintext, no TLS, no join auth. gRPC transport has mTLS
   (grpc_transport.go:221); gossip does not.
2. [HIGH, worse than auditor stated] The signature path is UNWIRED:
   SetPeerSigningKey has ZERO production callers (tests only), so with
   RequireNodeSignatures=true every event is rejected ("no signing key
   for event sender"); with the default false, all events are accepted
   unsigned. Either way signatures protect nothing today.
   (gossip.go:463-478, config.go setDefault leaves it false.)
3. [MEDIUM-HIGH] executor_bridge.go:175 HandleTaskCreate: any peer's
   TASK_CREATE dispatches a job locally; no authz; the ed25519 TODO at
   :198 acknowledges it.
4. [REAL, parent-found] Replay re-dispatches: gossip.go:502-507 calls
   persistEvent (INSERT OR IGNORE) then emitToHandlers UNCONDITIONALLY.
   The in-memory dedup cache (xxhash of attacker-settable EventID,
   1h TTL, cleared on restart) is the ONLY guard on handler dispatch.
   A replayed event_id re-runs handlers (incl. TASK_CREATE) even
   though the DB insert is ignored. Fix: skip emitToHandlers when
   persistEvent reports RowsAffected==0 (durable dedup).
5. [MEDIUM] cluster_events table (queue/store.go:306): no retention
   sweep anywhere — unbounded growth.
6. [LOW] No quorum; first-writer-wins. Accepted design for v0.

## Fix disposition (fix-all authorized)
- FIXING (one fixer): (a) replay-dispatch guard via RowsAffected;
  (b) cluster_events retention sweep (bounded, config'd);
  (c) loud startup warning when cluster enabled + signatures off +
  non-loopback gossip bind (same pattern as agentaudit endpoint-trust
  warning). TLS/mTLS for gossip + peer-key distribution = design work,
  logged for a plan leaf, NOT a bughunt fix.
- DEFER (logged): mTLS transport, join handshake, registry-backed
  peer keys, executor-bridge authz (needs the key distribution first).
