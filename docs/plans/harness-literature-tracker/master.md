## Meta

- **Role:** Root
- **Parent:** none (root)
- **Children:** 3 leaf documents under this node
- **Scope:** Living map of agent-harness techniques vs meept, with a regressive evidence check and an optional arXiv refresh.

## Goal

Ship a catalog that answers: which harness techniques does meept already implement, which are partial, which are candidates, and which papers/repos they come from.

A script verifies evidence paths still exist in the repo (regressive). The same script can optionally query arXiv and write a dated snapshot of new papers. Markdown is generated from the catalog so docs cannot drift from the JSON.

User-visible outcome: `docs/research/harness-techniques.md` plus `make research-harness` / `make research-harness-check`.

## Architecture

JSON catalog is the source of truth (`docs/research/harness-techniques.json`). Python 3 stdlib-only script loads it, verifies `evidence[].path` (and optional `must_contain`) for `shipped`/`partial` rows, then renders markdown. `--check` fails if evidence is missing or the markdown is stale. `--search` is network-optional and never mutates the catalog automatically.

A partial catalog already exists from an aborted implement pass. Leaf 01 audits and fixes it. Do not treat it as complete.

## Interface Contracts

### Contract 1: Catalog schema

File: `docs/research/harness-techniques.json`

```
{
  "version": 1,
  "updated": "YYYY-MM-DD",
  "description": string,
  "search_queries": [string, ...],
  "techniques": [
    {
      "id": "kebab-case-id",
      "name": string,
      "category": "context" | "loop" | "tools" | "routing" | "memory" | "security" | "interop" | "skills" | "observability",
      "status": "shipped" | "partial" | "candidate" | "skip",
      "sources": [{"title": string, "url": string}],
      "evidence": [{"path": string, "must_contain": string?}],
      "commits": ["short-sha", ...]?,
      "notes": string
    }
  ]
}
```

`commits[]` is optional provenance: git SHAs that landed the technique, mined from `git log -i --grep` (first pass 2026-08-29: HALO/RLM d3b430d2). Not verified by the script; documentation only.

Owner: 01-catalog.md. Consumers: 02-script.md, 03-wiring.md.

Rules:

- `url` may be http(s) or a repo-relative path (e.g. `analysis/pi-agent.md`).
- `shipped` and `partial` MUST have at least one `evidence` path that exists.
- `candidate` and `skip` MAY have empty evidence.
- Paths are repo-relative. Never point into `scratch/`.
- Directories are allowed as evidence (must exist).

### Contract 2: Script CLI

File: `scripts/research-harness-lit.py`

```
python3 scripts/research-harness-lit.py            # verify + render md
python3 scripts/research-harness-lit.py --check    # verify + fail if md stale
python3 scripts/research-harness-lit.py --search   # arXiv snapshot (network)
```

Exit 0 on success. Exit 1 if any shipped/partial evidence path is missing, `must_contain` fails, or `--check` sees markdown drift.

Owner: 02-script.md. Consumer: 03-wiring.md.

### Contract 3: Generated markdown

File: `docs/research/harness-techniques.md`

- First line: HTML comment `<!-- generated by scripts/research-harness-lit.py; do not edit -->`
- Group tables by category.
- Columns: technique, status, sources, evidence, notes.
- Status counts at the top (shipped / partial / candidate / skip).
- Link resolution: the md lives at `docs/research/harness-techniques.md`. Repo-relative source `url` values (e.g. `analysis/pi-agent.md`) must be rendered as links relative to the md file (`../analysis/pi-agent.md`), or mkdocs page links break. http(s) urls render as-is.

Owner: 02-script.md (generator). Leaf 03 only runs the generator; it does not hand-edit the md.

### Contract 4: Make targets

```
make research-harness         # python3 scripts/research-harness-lit.py
make research-harness-check   # python3 scripts/research-harness-lit.py --check
```

`research-harness-check` is added to `audit-scripts` so `make lint-ci` regressively fails if evidence files vanish.

Owner: 03-wiring.md.

## Coding Conventions

- **Language/Framework:** Python 3 stdlib only for the script (no PyYAML, no pip install). JSON catalog. Markdown generated.
- **Naming:** catalog ids kebab-case. Script filename `research-harness-lit.py`.
- **Imports:** stdlib only: json, argparse, hashlib, os, sys, pathlib, urllib.request, xml.etree, datetime, tempfile.
- **Error handling:** print to stderr, exit 1. No traceback dumps on expected verify failures.
- **Testing:** script `--check` is the primary test. Optional unittest in `scripts/research_harness_lit_test.py` if leaf 02 adds it.
- **Formatting tool:** none required for JSON/md. Python: 4-space indent, no black required.
- **File headers:** script shebang `#!/usr/bin/env python3` plus module docstring. No copyright boilerplate.
- **Scope greps:** never treat `scratch/` as meept implementation evidence.
- **Do not install software.** arXiv `--search` uses urllib only.
