# SHARED CONVENTIONS — LLM Resilience Forest

This file is referenced by all five trees in this forest (`01-escalation/`,
`02-failure-policy/`, `03-turn-lifecycle/`, `04-scheduling/`, `05-catalog/`).
Every leaf dispatch context must inline the sections relevant to that leaf.

## 1. Project facts

- Language: Go (module `github.com/caimlas/meept`). Formatting: `gofmt`.
- Tests: stdlib `testing`, table-driven where natural. Run: `go test ./internal/...`.
- Lint gates before any commit: `go vet ./...`, `gofmt -l` clean, and the
  repo analyzers (`make analyzers` runs mutexio + predid). `fieldguard` and
  `selflock` also run in CI — see AGENTS.md.
- Config format: JSON5. Schema lives in `internal/config/schema.go` with
  `json:"..." toml:"..."` struct tags on every field. Every new config field
  needs: schema field, default in `NewDefaultConfig` (or equivalent), a
  getter used at runtime, and a doc line in `docs/configuration/`.
- Bus topics are string-typed; the connectivity graph is regenerated by
  `make graphs` on every build. New topics must land in the correct
  WS-event bucket in `internal/comm/http/server.go` `transformBusEventToWS`
  (chat lifecycle topics → `agent_progress`, never `chat_message`).
- UI text is lowercase everywhere (TUI + Flutter).
- TUI and Flutter GUI must stay at feature parity for any user-visible
  surface added by these trees.

## 2. Repo invariants these trees must not break

- **Quota-reset-resilience contract** (AGENTS.md "Critical Invariants"):
  `*llm.QuotaResetError` never reaches `Resolver.RecordAliasFailure`; the
  agent loop's quota branch returns BEFORE the failure path; no client
  retry loop ever short-retries a quota error. Tree 02 extends these
  contracts; it does not weaken them.
- **All-blocked is distinct:** `ErrAllModelsQuotaBlocked` (never return a
  blocked model). Preserved.
- **`agent.StateQuotaWait` reachability:** any new agent state needs a
  transition-table entry (`SafeTransition`), else it is unreachable.
  Tree 03's new parked states must follow the same pattern.
- **RPC vs HTTP trust boundary:** parked-turn resume must never smuggle an
  RPC identity into HTTP-owned sessions. Park records ride the same
  surfaces as `QuotaResumeWatcher` does today.
- **Mutex scope:** collect-under-lock, operate-after-release. The
  `mutexio` analyzer flags I/O under lock; suppress only with an
  explanatory `//nolint:mutexio` on the specific call site.
- **Typed-nil guards** on every `Set*` method; **no `_ = f()` ignored
  errors; two-value type assertions on `map[string]any` bus payloads.
- **Predictable-ID ban:** IDs via `pkg/id.Generate()`; never
  `time.Now().UnixNano()` or `math/rand`.
- **Daemon CWD is not the user's project:** no `os.Getwd()` fallbacks in
  `internal/` runtime paths.

## 3. Coding conventions (pass verbatim to every leaf)

- Go stdlib first; no new third-party deps without naming the module and
  its license in the leaf's Deviations.
- Errors: wrap with `fmt.Errorf("context: %w", err)`, return early.
- Comments explain WHY; reference the invariant or decision ID
  (`DECISIONS.md D#`) that motivates non-obvious behavior.
- Tests alongside source: `foo.go` → `foo_test.go` in the same package
  (white-box allowed; the repo uses in-package tests).
- No debug prints, no TODOs without a decision reference, no commented-out
  code, no placeholder values in shipped code.
- After writing a file, do NOT read it back to verify — write once and
  stop. Never feed `read_file` output into `write_file`.

### 4.1 FailurePolicy verdict (trees 02 → 03/04)

```go
// File: internal/llm/failure_policy.go (tree 02 creates)
package llm

// FailureClass buckets an LLM-provider error response.
type FailureClass int

const (
    FailureNone       FailureClass = iota // not a failure
    FailureThrottle                        // 429/503, provider load; long-horizon backoff
    FailureQuota                           // 429/402 with quota-shaped signal; park until reset
    FailureServerError                     // 5xx; bounded retry
    FailureFatal                           // 4xx except 402/429; no retry
)

// PolicyVerdict is the single decision returned for any provider error.
type PolicyVerdict struct {
    Class      FailureClass
    RetryAt    time.Time     // earliest next attempt; zero = no retry scheduled
    Park       bool          // true = park the turn, release the agent slot
    GiveUp     bool          // true = surface a user-facing failure now
    Reason     string        // machine-readable, e.g. "retry_after_header", "keyword_quota"
}

// Classify is the ONE entry point all clients call for any non-2xx
// response or transport error. Returns FailureNone for transient network
// errors that the transport layer already retries.
func Classify(statusCode int, header http.Header, body []byte, now time.Time) PolicyVerdict
```

## 5. Test strategy

- Unit tests per module (table-driven, in-package).
- Time-dependent logic (backoff schedules, park/resume) uses injected
  clock or `now func() time.Time` field — no real sleeps over 100ms in
  tests.
- Cross-tree integration checks live in each tree's Integration Test Plan,
  not here.

## 6. Commit policy

Only orchestrators commit. Implementation agents do NOT commit, do NOT
`git add`. Commit message style: conventional (`feat(llm): ...`,
`fix(agent): ...`), reference the leaf document by path in the body.
Per meept convention, cite plan/decision ids in commit bodies when the
change implements a specific planned decision.

## 7. Known pitfalls for this forest

- The five client retry loops (openai non-streaming ~client.go:426,
  openai streaming ~client.go:586, streaming-delta ~client.go:1269 —
  NOTE: the delta loop's constant is `streamMaxRetries`, NOT
  `maxRetries`; grep BOTH when locating loops, anthropic
  non-streaming ~anthropic.go:281, anthropic streaming ~anthropic.go:448)
  share copy-pasted backoff logic with hardcoded `maxRetries = 3` /
  30s cap. Tree 02 replaces all five with the policy engine; a leaf must
  NOT leave a sixth divergent copy behind.
- `RateLimitError` currently survives only via the agent-loop branch at
  `loop.go:~4298` (errors.As RateLimitError). Trees 02/03 must keep that
  branch working while the classification moves underneath it.
- AliasHealth has ONE alias-level `CooldownUntil`; per-entry quota blocks
  (`entryBlocks`) are the per-model precedent. Endpoint-level timeout
  state (tree 02) lives on the RESOLVER STRUCT next to the health map —
  NOT on AliasHealth (per-alias state cannot deliver D10's cross-alias
  shared fate; audit B3) — same lock regime (Resolver.mu guards
  everything; document "callers must hold Resolver.mu").
- The PrepareNextTurn hook pipeline is UNWIRED in production (audit B1):
  HookRegistry.RunPrepareNextTurn (hooks.go:267) has zero production
  callers; loop.go runs only SessionStart/SessionEnd hooks. Tree 01
  leaf 02 wires it before any hook-based leaf can work.
- `*llm.Resolver` already has `ResolveRef(ref string) *ModelConfig`
  (resolver.go:294) — tree 01's resolver method MUST be named
  `ResolveEscalationRef` (audit B2) or the package will not compile.
- Transport-level timeouts (no HTTP status/body) reach
  RecordAliasFailure WITHOUT passing Classify (audit M4): tree 02 leaf 04
  must route the transport-error path through the policy engine too (a
  FailureNone-class transport wrapper), or endpoint cooldowns will fire
  on quota/429s but never on true timeouts.
- `classifyQuotaDecision` (errors_quota.go:131) already splits short-cycle
  vs quota-shaped; tree 02 generalizes it — keep its existing tests green
  by preserving observable classification for the cases it covers.
- AGENTS.md must be reviewed and updated in the same commit as any change
  that adds config fields, bus topics, agent states, or new conventions.
